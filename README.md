# Movilidad Xalapa - Base de Datos Orientada a Objetos (BDOO)

Sistema de gestión para renta de vehículos desarrollado con Python y ZODB.

## Integrantes
* **Helena Martínez** (ux24ii401) 

## Tecnologías
* Python 3.x
* ZODB & Persistent
* Git & GitHub

## Instrucciones de Uso
1. Activar entorno virtual: `.\venv\Scripts\Activate.ps1`
2. Instalar dependencias: `pip install ZODB persistent`
3. Ejecutar demostración: `python main.py`
